# 8051（MCS-51）單晶片

## 8051 架構概觀
id: i8051-overview
category: 概念
arch: 8051
tags: 8051, 單晶片, MCS-51, 89C51, 89S52, 架構, ROM, RAM, SFR, 哈佛架構
---
8051 是 8 位元微控制器，台灣「微處理機／單晶片」課程最常用（AT89S51/52 等相容晶片）。
・程式記憶體（ROM/Flash）：4KB（8052 為 8KB），與資料記憶體分開（哈佛架構）
・內部 RAM：128 位元組（00h～7Fh），8052 為 256
  - 00h～1Fh：4 組暫存器庫（R0～R7），由 PSW 的 RS1、RS0 選擇
  - 20h～2Fh：可位元定址區（128 個位元）
  - 30h～7Fh：一般資料區（堆疊常放這裡）
・特殊功能暫存器（SFR）：80h～FFh，例如 P0～P3、ACC、B、PSW、SP、DPTR、TMOD、TCON
・4 個 8 位元 I/O 埠 P0～P3、2 個 16 位元計時器、1 個 UART、5 個中斷源
・一個機器週期 = 12 個時脈（12MHz 時為 1μs）

## 8051 暫存器
id: i8051-registers
category: 概念
arch: 8051
tags: 8051, 暫存器, A, ACC, B, R0, R7, DPTR, PSW, SP, PC, 暫存器庫
---
```
A（ACC）  累加器，大部分運算都要經過 A
B         乘除法使用（MUL AB、DIV AB）
R0～R7    工作暫存器（R0、R1 可做間接定址 @R0、@R1）
DPTR      16 位元資料指標（DPH:DPL），存取外部記憶體或查表
SP        堆疊指標，重置後為 07h，PUSH 時先加 1（往高位址長）
PC        程式計數器（16 位元）
PSW       程式狀態字組
```
注意：重置後 SP = 07h，第一次 PUSH 會寫到 08h，剛好和暫存器庫 1 重疊；如果有用到其他暫存器庫，程式開頭常寫 MOV SP, #60h。

## 8051 PSW 旗標
id: i8051-psw
category: 概念
arch: 8051
tags: 8051, PSW, CY, AC, OV, P, RS0, RS1, 旗標, 暫存器庫切換
---
```
位元  7    6    5    4    3    2    1    0
      CY   AC   F0   RS1  RS0  OV   -    P
```
・CY：進位旗標（也是位元運算的累加器 C）
・AC：輔助進位（BCD 調整用）
・F0：使用者自訂旗標
・RS1 RS0：選擇暫存器庫 00=庫0(00h～07h)、01=庫1、10=庫2、11=庫3
・OV：有號溢位；MUL 結果 > 255 或 DIV 除以 0 時也會設定
・P：同位旗標（A 中 1 的個數為奇數時 P=1）

8051 沒有零旗標！判斷 A 是否為 0 用 JZ／JNZ，比較用 CJNE。

## 8051 定址模式
id: i8051-addressing
category: 概念
arch: 8051
tags: 8051, 定址模式, 立即定址, 直接定址, 間接定址, 暫存器定址, 索引定址, 位元定址, #, @R0
---
```
立即定址      MOV A, #25H        # 表示常數
直接定址      MOV A, 25H         讀取 RAM 位址 25h 的內容（沒有 #！）
暫存器定址    MOV A, R3
間接定址      MOV A, @R0         位址存在 R0（只能用 R0、R1）
外部記憶體    MOVX A, @DPTR      讀外部 RAM
索引定址      MOVC A, @A+DPTR    讀程式記憶體（查表）
位元定址      SETB P1.0 / MOV C, 20H.3
```
最常見的錯誤：把 MOV A, #30H（放入常數 30h）寫成 MOV A, 30H（讀取位址 30h 的內容）。

## 8051 延遲副程式與時間推導
id: i8051-delay
category: 推導
arch: 8051
tags: 8051, 延遲, delay, DJNZ, 機器週期, 時間推導, 12MHz, 巢狀迴圈
---
機器週期 = 12 ÷ 石英頻率。12MHz → 1μs；11.0592MHz → 約 1.085μs。
指令週期：MOV Rn,#data = 1、DJNZ = 2、ACALL/LCALL = 2、RET = 2、NOP = 1。

```
DELAY:  MOV  R6, #200     ; 1
D1:     MOV  R7, #250     ; 1
D2:     DJNZ R7, D2       ; 2
        DJNZ R6, D1       ; 2
        RET               ; 2
```
推導（12MHz）：
```
內層：250 × 2 = 500 週期
外層每圈：1 + 500 + 2 = 503 週期，共 200 圈 = 100600 週期
總計：1 + 100600 + 2 = 100603 週期 ≈ 100.6 ms（再加 ACALL 2 週期）
```
估算：2 × 200 × 250 μs = 100 ms。
「數值推導」頁輸入頻率與各層次數就能得到完整推導，例如「8051 12MHz 延遲 200 250」。

## LED 閃爍與跑馬燈
id: i8051-led
category: 範例
arch: 8051
tags: 8051, LED, 閃爍, 跑馬燈, P1, CPL, RL, 範例, 程式
---
LED 閃爍（P1.0，低電位亮）：
```
        ORG  0000H
MAIN:   CPL  P1.0        ; 反相
        ACALL DELAY
        SJMP MAIN
```
跑馬燈（8 顆 LED 接 P1，低電位亮）：
```
        ORG  0000H
        MOV  A, #0FEH     ; 1111 1110
LOOP:   MOV  P1, A
        ACALL DELAY
        RL   A            ; 往左旋轉，亮點移動
        SJMP LOOP
```
RL 是 8 位元循環，所以亮點會一直轉圈；要來回跑可以用 RL 跑 7 次再 RR 跑 7 次。
P0 是開汲極輸出，接 LED 時需要外加提升電阻。

## 8051 計時器（Timer0 模式 1）
id: i8051-timer
category: 推導
arch: 8051
tags: 8051, 計時器, timer, TMOD, TCON, TH0, TL0, TR0, TF0, 模式1, 初值, 推導, 65536
---
TMOD（高 4 位元給 Timer1、低 4 位元給 Timer0）：GATE、C/T、M1、M0
・模式 0：13 位元；模式 1：16 位元；模式 2：8 位元自動重載；模式 3：分割
・C/T=0 計時（數機器週期）、C/T=1 計數（數外部腳位脈波）

初值推導（12MHz，延遲 50ms）：
```
機器週期 1μs → 需要計數 50000 次
模式 1 最大 65536：初值 = 65536 - 50000 = 15536 = 3CB0h
TH0 = 3Ch，TL0 = B0h
```
程式：
```
        MOV  TMOD, #01H       ; Timer0 模式 1
WAIT50: MOV  TH0, #3CH
        MOV  TL0, #0B0H
        SETB TR0              ; 開始計時
        JNB  TF0, $           ; 等到溢位
        CLR  TR0
        CLR  TF0              ; 旗標要手動清除（用中斷時會自動清）
        RET
```
1 秒 = 呼叫 20 次 50ms。

## 8051 中斷
id: i8051-interrupt
category: 概念
arch: 8051
tags: 8051, 中斷, interrupt, IE, IP, EA, 中斷向量, RETI, INT0, 外部中斷, 計時器中斷
---
中斷向量位址：
```
0003H  外部中斷 INT0（P3.2）
000BH  Timer0 溢位
0013H  外部中斷 INT1（P3.3）
001BH  Timer1 溢位
0023H  序列埠（RI/TI）
```
啟用中斷：SETB EA（總開關）＋個別開關（ET0、EX0、ES…）。外部中斷設 IT0=1 為負緣觸發。
```
        ORG  0000H
        LJMP MAIN
        ORG  000BH
        LJMP T0_ISR          ; 向量只有 8 位元組，通常跳到別處
MAIN:   MOV  TMOD, #01H
        MOV  TH0, #3CH
        MOV  TL0, #0B0H
        SETB ET0
        SETB EA
        SETB TR0
        SJMP $
T0_ISR: MOV  TH0, #3CH       ; 重新載入初值
        MOV  TL0, #0B0H
        CPL  P1.0
        RETI                 ; 中斷要用 RETI 返回
```

## 七段顯示器查表
id: i8051-seven-segment
category: 範例
arch: 8051
tags: 8051, 七段顯示器, 7-segment, 查表, MOVC, DPTR, 共陽, 共陰
---
用 MOVC A, @A+DPTR 查表，把數字 0～9 轉成字型碼：
```
        MOV  DPTR, #TABLE
        MOV  A, #5           ; 要顯示的數字
        MOVC A, @A+DPTR      ; A = 第 5 個字型碼
        MOV  P1, A
        ...
TABLE:  DB 0C0H, 0F9H, 0A4H, 0B0H, 99H, 92H, 82H, 0F8H, 80H, 90H   ; 共陽極 0～9
```
共陰極的字型碼剛好是共陽極的反相（例如 0 為 3FH）。多位數顯示要用掃描（輪流點亮每一位並快速切換）。

## 8051 序列埠與鮑率推導
id: i8051-uart
category: 推導
arch: 8051
tags: 8051, 序列埠, UART, 鮑率, baud, TH1, SCON, SBUF, 11.0592MHz, 推導
---
Timer1 模式 2 產生鮑率：
```
TH1 = 256 - (2^SMOD × 石英頻率) ÷ (384 × 鮑率)
```
11.0592MHz、9600 bps、SMOD=0：
```
11059200 ÷ (384 × 9600) = 3
TH1 = 256 - 3 = 253 = FDh
```
程式：
```
        MOV  TMOD, #20H      ; Timer1 模式 2
        MOV  TH1, #0FDH
        MOV  SCON, #50H      ; 模式 1（8 位元 UART），允許接收
        SETB TR1
SEND:   MOV  SBUF, A         ; 傳送
        JNB  TI, $
        CLR  TI
```
12MHz 無法剛好整除常見鮑率，誤差較大，所以 UART 應用常選 11.0592MHz。
