# ASSAM：離線組合語言 AI 助理

ASSAM 是用 **Visual Studio 2019 + C#（.NET Framework 4.7.2，WinForms）** 寫成的桌面程式，可以：

- **偵測**：自動判斷一段程式是哪一種組合語言（x86 Intel／AT&T、ARM、ARM64、MIPS、RISC-V、8051、AVR）
- **找尋資訊**：用中文或英文問觀念、指令、做法，從內建知識庫找出答案（約 650 筆知識卡）
- **解釋程式**：逐行說明每一行在做什麼、使用哪種定址模式，並找出迴圈、副程式、系統呼叫與常見錯誤
- **推導**：x86 程式一步一步模擬執行，列出每一步暫存器、旗標、記憶體的變化和「為什麼」
- **數值推導**：進位轉換、二補數、加減法旗標、8086 實體位址、移位、8051 延遲／計時器／鮑率
- **學習與記憶**：根據你的回饋調整答案、記住你教的知識和更正，記憶**存在本機**

全部功能都**離線**運作：不連網、不呼叫任何雲端服務，也不用 NuGet 套件，所以建置時也不需要網路。對電腦要求很低，1GB 記憶體的舊電腦也能跑。

---

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 7 SP1／8.1／10／11（32 或 64 位元） |
| 執行環境 | .NET Framework 4.7.2 以上（Windows 10 1803 之後已內建） |
| 記憶體 | 1 GB 以上即可（程式本身約使用數十 MB） |
| 硬碟 | 約 5 MB（加上學習記憶檔，通常小於 1 MB） |
| CPU | 任何能跑 Windows 7 的 CPU；不需要 GPU |
| 開發工具 | Visual Studio 2019（任何版本，含 Community），安裝「.NET 桌面開發」工作負載 |

> 為什麼沒有用大型語言模型？大型模型需要好幾 GB 的記憶體與高階顯示卡，不符合「設備不能太高檔」的需求。
> ASSAM 改用輕量的傳統 AI 方法（檢索、機率分類、線上學習、專家規則、指令模擬），在舊電腦上也能即時回應。

## 快速開始（Visual Studio 2019）

1. 用 VS2019 開啟 `ASSAM.sln`
2. 確認方案組態為 `Debug`、平台為 `Any CPU`
3. 在方案總管把 **Assam.App** 設為起始專案（預設就是）
4. 按 **F5** 執行

執行檔在 `src\Assam.App\bin\Debug\ASSAM.exe`。要發佈給別人，只要把 `bin\Release` 資料夾中的 `ASSAM.exe`、`ASSAM.exe.config`、`Assam.Core.dll` 三個檔案複製過去即可，不需要安裝。

> 介面全部用程式碼建立（類別標註 `DesignerCategory("Code")`），在 VS 中雙擊表單檔會直接開啟程式碼，而不是設計工具。

## 介面

| 分頁 | 用途 |
| --- | --- |
| **智慧問答** | 輸入問題或貼上程式碼（Ctrl+Enter 送出）。可以按「有幫助／沒幫助」、從右側清單選「這個才是答案」、「教我正確答案」、更正問題類型，ASSAM 都會記住 |
| **程式碼分析** | 貼上或開啟 .asm 檔，自動辨識架構並逐行解說（說明＋虛擬碼動作），列出迴圈、副程式、系統呼叫與注意事項。判斷錯誤時選擇正確架構並按「更正架構並學習」 |
| **推導模擬（x86）** | 逐步執行 x86 程式（MASM／NASM 寫法），可設定初始暫存器（例如 `EAX=5, EBX=3`）與模擬鍵盤輸入；點選每一步可看推導過程與當時的暫存器 |
| **數值推導** | 十個計算工具，每個都列出手算步驟 |
| **知識庫** | 瀏覽／搜尋所有知識；新增、編輯、刪除自己的知識；替指令寫個人筆記 |
| **學習記憶** | 查看學到的內容與歷史紀錄；匯出備份、匯入、清除記憶、重新載入知識庫 |

### 問答範例

```
LOOP 指令怎麼用
jg 和 ja 有什麼不同
8051 跑馬燈怎麼寫
寄存器有哪些                 ← 簡體字也可以
how to swap two variables
mov eax, [ebx+4] 是什麼意思   ← 問句中夾帶的指令會被解釋

執行後 EAX 是多少？          ← 下一行開始貼程式碼，就會一步一步推導
mov eax, 7Fh
add eax, 1

這是什麼組合語言？
lw $t0, 4($sp)

0x7F 轉二進位
-5 的 8 位元二補數
8 位元 7Fh + 1 的旗標
1234:0010 的實體位址
8051 12MHz 延遲 200 250
12MHz 計時器 50ms 初值
11.0592MHz 鮑率 9600
```
快速指令：`/help`、`/stats`、`/teach 問題 => 答案`、`/explain 程式碼`、`/sim 程式碼`、`/detect 程式碼`。

## AI 是怎麼運作的

| 功能 | 方法 | 位置 |
| --- | --- | --- |
| 中文理解 | 中英混合斷詞（中文單字＋雙字詞）、全形轉半形、常用簡體轉繁體、同義詞擴展（暫存器＝register…） | `Core/Text` |
| 知識檢索 | BM25 排名（標題／標籤加權）＋架構偏好＋指令名稱加分 | `Core/Search/SearchEngine.cs` |
| 回饋學習 | 相關回饋：「問題中的詞 → 知識卡」權重表，以及「整句問題 → 答案」記憶 | `SearchEngine.Learn` |
| 問題類型判斷 | 多項式單純貝氏分類器，以內建例句訓練，使用者更正的例句權重較高 | `Core/Assistant/IntentClassifier.cs` |
| 架構辨識 | 可解釋的線性模型（指令集比對、暫存器、`%`／`$`／`#`／`[ ]` 等語法特徵），更正時用 Passive-Aggressive 線上學習調整權重 | `Core/Analysis/ArchitectureDetector.cs` |
| 程式解說 | 專家規則＋資料驅動的指令表（說明、旗標、虛擬碼樣板）＋定址模式分析＋結構分析＋錯誤檢查 | `Core/Analysis` |
| 推導 | x86 指令模擬器，精確計算 CF/OF/ZF/SF/PF/AF 並產生中文推導 | `Core/Simulation` |
| 數值推導 | 逐步產生手算過程 | `Core/Derivation` |

## 學習記憶存在哪裡

- 預設在**程式資料夾**的 `UserData\`（可攜式，用隨身碟帶著走也會記得）。
- 如果程式資料夾不能寫入（例如裝在 `C:\Program Files`），改存在 `%LocalAppData%\ASSAM\`。
- `memory.json`：所有學習內容（JSON 純文字，UTF-8）。每次寫入都先寫暫存檔再取代，並保留 `memory.json.bak`；檔案損毀時會另存一份並自動重建。
- `Knowledge\`：放你自己的 `.md` 知識檔，按「重新載入知識庫」就會加入。

記憶包含：教學的知識、回饋權重、整句答案、架構辨識的權重修正與樣本、問題類型更正樣本、指令筆記、最近 300 筆問答紀錄。

## 擴充知識

### 知識檔格式（.md）

```
## 標題
id: my-unique-id
category: 概念          （概念／指令／做法／推導／範例／除錯）
arch: x86               （x86／8051／ARM／ARM64／MIPS／RISC-V／AVR／通用，也可以自訂）
tags: 標籤1, 標籤2
---
內文……可以使用 ``` 程式碼區塊。
```

- 內建知識在 `src/Assam.Core/Knowledge/Data/*.md`（以內嵌資源編進 DLL）。修改後重新建置即可。
- 個人知識放在 `UserData\Knowledge\*.md`，不用重新建置。範例見 [`docs/custom-knowledge-example.md`](docs/custom-knowledge-example.md)。

### 指令表格式（.txt）

`src/Assam.Core/Instructions/Data/*.txt` 每一行是一個指令：

```
助憶碼(同義用 / 分隔) | 分類 | 影響旗標 | 語法 | 說明 | 動作樣板
ADD | 算術 | N Z C V（加 S 時） | ADD Rd, Rn, Op2 | 加法：Rd = Rn + Op2。 | 2:{0} ← {0} + {1} || 3:{0} ← {1} + {2}
```
動作樣板中的 `{0}`、`{1}` 代表運算元；`2:`、`3:` 前綴代表運算元個數不同時使用的版本。每個指令也會自動變成一張「指令卡」供問答查詢。新增架構時：加一個 .txt 檔、在 `AsmArch` 列舉與 `ArchitectureDetector` 的初始權重加入對應項目，並把檔案加入 `Assam.Core.csproj` 的 `EmbeddedResource`。

## 執行測試

在 VS2019 把 **Assam.Tests** 設為起始專案，按 **Ctrl+F5**；或在命令列執行
`tests\Assam.Tests\bin\Debug\Assam.Tests.exe`（可加篩選字串，例如 `Assam.Tests.exe Simulator`）。
目前共 81 項測試，涵蓋數值推導、行解析、架構辨識與學習、程式解說、x86 模擬器、知識庫、搜尋與回饋學習、記憶存檔與損毀復原、離線檢查（核心不可引用網路組件）與啟動效能。

## 支援範圍與限制

- **推導模擬**只支援 x86／x64 的整數指令（Intel 語法，MASM 與 NASM 常見寫法），包含算術、邏輯、移位、乘除、堆疊、副程式、條件跳躍、字串指令、SETcc／CMOVcc、DOS INT 21h、BIOS INT 10h、Linux INT 80h／SYSCALL 與 Irvine32 常用程序。浮點（FPU／SSE）、巨集展開、區段權限等不模擬；其他架構提供逐行說明與虛擬碼動作，方便手動推導。
- 模擬器的位址（ESP 初值、資料區位址、返回位址）是固定的「教學用位址」，和真實作業系統執行時不同。
- 架構辨識對很短的片段（例如只有一行 `mov r0, #5`）可能無法分辨 ARM 與 8051，這時可以手動選擇架構，或更正讓它學習。
- 回答來自內建知識庫與你教的內容，不會自行「創作」新知識；找不到答案時會明確告訴你，並請你教它。

## 常見問題

**Q：可以在完全沒有網路的電腦上建置嗎？**
可以。專案沒有使用任何 NuGet 套件，只需要 VS2019 與 .NET Framework 4.7.2 目標套件（安裝「.NET 桌面開發」時已包含）。

**Q：中文顯示成亂碼？**
原始碼是 UTF-8（含 BOM）。若用其他編輯器修改，請以 UTF-8 儲存。知識檔（.md）也請使用 UTF-8。

**Q：想把學習記憶搬到另一台電腦？**
在「學習記憶」頁按「匯出記憶」，到另一台電腦按「匯入記憶」；或直接複製整個 `UserData` 資料夾。

**Q：怎麼讓它回答學校課程的特定內容？**
在問答頁按「教我正確答案」，或把整理好的 `.md` 知識檔放到 `UserData\Knowledge\`。
